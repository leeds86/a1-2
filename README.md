# 🗺️ AI 기반 국내 여행 추천 및 맛집 가이드 프로그램

Gemini AI(LLM)와 카카오맵 API를 활용하여, 입력한 날짜에 가기 좋은 국내 여행지를 추천하고 지역별 맛집 리스트를 포함한 깔끔한 여행 리포트를 자동 생성하는 프로그램입니다.

## ✨ 주요 기능
* **복수 지역 추천:** 1개의 지역이 아닌 2~3개의 맞춤형 여행지를 추천합니다.
* **지역별 맛집 검색:** 카카오맵 API를 활용해 추천된 지역의 실제 맛집 정보와 지도 링크를 제공합니다.
* **결과 캐싱 (최적화):** 동일한 날짜로 다시 실행할 경우, 불필요한 API 비용을 아끼기 위해 이전에 검색한 데이터를 재활용합니다.
* **자동 리포트 생성:** 생성된 정보들을 모아 보기 좋은 마크다운(.md) 형식의 문서로 자동 저장합니다.

---

## 🚀 실행 방법 (가상 환경 사용)

최신 파이썬 환경에서는 시스템 충돌 방지를 위해 '가상 환경(나만의 작업 공간)'에서 실행하는 것을 권장합니다.

### 1. 패키지 설치 (최초 1회만)
터미널(명령 프롬프트)을 열고 아래 명령어를 입력하세요.
```bash
pip install -r requirements.txt
```

### 2. 프로그램 실행
가상 환경이 켜진 상태(`(myenv)`)에서 아래 명령어로 프로그램을 실행합니다.
```bash
python travel_planner/travel_planner.py --date 2026-10-10
```
*(날짜는 `YYYY-MM-DD` 형식으로 자유롭게 변경 가능합니다.)*

## 🔑 API 키 설정 방법 (.env)

이 프로그램이 정상적으로 작동하려면 구글 제미나이(Gemini)와 카카오(Kakao)의 API 키가 필요합니다.  
초보자도 쉽게 설정할 수 있도록 템플릿 파일(`.env.example`)을 함께 제공합니다.

1. 프로젝트 폴더에 있는 **`.env.example`** 파일의 이름을 **`.env`** 로 변경합니다. (파일명 앞에 점(.)이 있어야 합니다.)
3. 변경한 `.env` 파일을 열고, 아래와 같이 발급받은 키를 붙여넣고 저장합니다.

```env
# .env 파일 작성 예시
GEMINI_API_KEY=your_gemini_api_key_here(실제 발급받은 제미나이 키)
KAKAO_API_KEY=your_kakao_api_key_here(실제 발급받은 카카오 키)
```

### 🚨 [매우 중요] API 키 유출 주의!
* API 키는 본인의 지갑 비밀번호와 같습니다. 유출될 경우 타인이 무단으로 사용하여 **요금 폭탄**을 맞거나 계정이 정지될 수 있습니다.
* 코드를 **GitHub, 블로그, 외부 커뮤니티 등에 업로드할 때 절대 `.env` 파일을 함께 올리지 마세요.**
* GitHub을 사용하신다면 반드시 `.gitignore` 파일에 `.env`를 추가하여 업로드를 원천 차단하시기 바랍니다.

## 📂 결과물 확인 방법

프로그램이 성공적으로 실행을 마치면, 코드가 있는 위치에 **`results`** 라는 폴더가 새로 생깁니다.

* **`report_YYYY-MM-DD.md` (여행 리포트)** 
  * 완성된 최종 여행 리포트입니다. 
  * 마크다운(.md) 파일을 지원하는 뷰어나 Notion(노션) 등에 붙여넣기 하시면 맛집 카카오맵 링크까지 깔끔하게 클릭할 수 있는 형태로 확인할 수 있습니다.
* **`data_YYYY-MM-DD.json` (원본 데이터)**
  * AI와 카카오맵에서 받아온 원본 데이터입니다. 
  * 이 파일이 있으면 다음 번에 동일한 날짜로 실행할 때 외부 API를 호출하지 않고 빠르게 리포트만 다시 만들어냅니다.
